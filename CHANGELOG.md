# MC Displays 1.2.2 (Minecraft 1.20.1 Forge)

Welcome to MC Displays 1.2.2! This release fixes resource scroll and clipboard pagination on display panels.

---

### 🐛 Fixes & Improvements
- **Resource Scroll & Clipboard Pagination:** Removed arbitrary 10-line chunking from MineColonies data extraction. Display panels now render a continuous list across the entire available height of modular screens, eliminating unwanted `Source 1/X` section breaks on larger screen clusters.
