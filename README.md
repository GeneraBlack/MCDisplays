# MC Displays

MC Displays is a NeoForge mod for Minecraft 1.21.1 that adds modular multiblock wall displays. The panels can render book text directly in the world and also support MineColonies Resource Scrolls and Clipboards.

## Features

- Rectangular multiblock display walls built from individual panels
- In-world rendering for written books and books and quills
- MineColonies Resource Scroll support
- MineColonies Clipboard support
- Automatic refresh on a configurable interval
- Optional manual page turning
- In-game configuration screen

## Target Versions

- Minecraft 1.21.1
- NeoForge 21.1.218

## Development

Build the mod with:

```bash
./gradlew build
```

Start the development client with:

```bash
./gradlew runClient
```

For MineColonies integration tests in the dev client, the project includes local runtime dependencies for the MineColonies stack.

## CurseForge Assets

Repository branding assets for publishing are stored in the branding folder, including a 100x100 icon and an English CurseForge description draft.
